# Thomas 1983 水油渗吸细网格（单重介质 7×7×8）

## 1. 验证对象与文献对应

本目录复现 Thomas（1983）中一个被水包围的 **10 ft 立方基质块** 的水油渗吸算例，作为
单块双介质算例（`6.1_Thomas_water_oil_single_block`）的**细网格基准**。基质块内部垂向/横向流动
被显式离散，采收率来自逐单元的组分演化。

文献对应：

| 项目 | Thomas 1983 原文 | 本文输入 |
| --- | --- | --- |
| 基质块尺寸 | 10 ft（≈ 3.05 m） | 3.048 m 立方（内部 5×5×6 单元） |
| 初始压力 | 43 MPa（泡点之上，正文） | 4.3e7 Pa（静水） |
| 油相状态 | 欠饱和（无自由气） | `Sg=0`，泡点约 38.33 MPa |
| 外部环境 | 被水包围 | 恒组成恒压水（裂缝壳 Dirichlet） |
| 参考采收率 | Fig. 2：10 ft 块约 34.2%（2 年） | 平台值 34.2% |
| 终止时间 | 2 年 | `6.3072e7 s` |

## 2. 模型设置

### 2.1 几何与网格

单重介质 `InternalMesh mesh1`，`7×7×8 = 392` 单元：

- 内部 `5×5×6 = 150` 单元为**基质**（`matrixRegion`），非均匀分层
  x/y = `[1, 2, 4, 2, 1] ft`、z = `[1, 2, 2, 2, 2, 1] ft`，对应 Table 1 内部网格；
- 外层 1 ft 壳（242 单元）为**裂缝**（`fractureRegion`），作为恒水边界，**不演化**。

> 与气油细网格算例（`5_Thomas_fine_grid_depletion_liveoil`）不同，这里裂缝壳不用 0.001 ft
> 薄层，而是与相邻基质同尺寸的 1 ft 单元——因为油水中裂缝是恒组成恒压的水环境，无需
> 显式模拟裂缝几何/流动。

### 2.2 岩石与流体

| 项目 | 基质 | 裂缝壳 |
| --- | --- | --- |
| 本征孔隙度 | 0.30 | 1.0 |
| 渗透率 | 9.869233e-16 m²（1 md） | 9.869233e-13 m²（1000 md） |
| 毛管压力 | Thomas Table 3 水油 Pc | 0 |
| 相对渗透率 | Stone II 三相（Thomas Table 3） | 直线端点 |

- 黑油流体：`surfaceDensities={819.18, 0.929, 1041.2}`，
  `componentMolarWeight={120e-3, 25e-3, 18e-3}`，PVT 表见 `tables/`。
- 温度 `366 K`，重力 `g=(0,0,-9.81)`。

### 2.3 初始状态

- 基质：`P=4.3e7`（静水，油密度梯度），组分 `(oil,gas,water)=(0.540,0.167,0.293)`，
  对应 43 MPa 欠饱和活油；`gas` 组分是溶解气，初始无自由气相（`Sg=0`）。
- 裂缝壳：`P=4.3e7`（静水，水密度梯度），近纯水 `(oil,gas,water)=(0.0001,0,0.9999)`。

### 2.4 边界条件（恒组成恒压水）

裂缝壳单元用 `initialCondition=0` 的 Dirichlet 固定为恒定压力 + 恒定组成：

| 组分 | 值 |
| --- | ---: |
| 压力 | 4.3e7 Pa（静水） |
| oil | 0.0001 |
| gas | **0** |
| water | 0.9999 |

**关键：边界 `gas` 组分必须设 0。** 若给非零值（如 0.0001/0.0005），油被水排替到边界时
溶解气组分（C1）未与油组分（C1+）同步被移除，在近边界局部富集脱溶成自由气，再向基质内扩散，
虚增采收率。经验证：

| 边界 (oil, gas) | 采收率 | Sg_avg |
| --- | ---: | ---: |
| (0.0005, 0.0005) | 46.6% | 0.086 |
| (0.0001, 0.0001) | 42.3% | 0.032 |
| (0.0001, **0**) | **34.23%** | **0** |

## 3. 运行结果

GEOS 推进到 `6.3072e7 s`（2 年），运行正常结束。油组分采收率（基质全部单元求和）如下，
Thomas Fig. 2 列为论文插图 `imbibition recovery, 10-ft block` 的读图值（`reference/thomas_fig2_10ft.csv`，
±1 pp 不确定度）：

| 时间 / 年 | 采收率 / % | Thomas Fig. 2 / % | 差值 / pp |
| ---: | ---: | ---: | ---: |
| 0.10 | 21.375 | 18.2 | +3.175 |
| 0.20 | 24.927 | 21.6 | +3.327 |
| 0.50 | 30.246 | 27.7 | +2.546 |
| 1.00 | 33.301 | 31.6 | +1.701 |
| 1.50 | 34.071 | 33.4 | +0.671 |
| **2.00** | **34.230** | **34.1** | **+0.130** |

![细网格采收率与 Thomas Fig. 2 对比](analysis/figures/recovery_comparison.png)

终态（体积加权平均）`So=0.527, Sw=0.473, Sg=0.000`，对应平衡
`Pc_wo = -(ρ_w − ρ_o) g H/2 ≈ -5.8 kPa`，与 Thomas 给出的平衡条件一致。

## 4. 结论

- 终值 **34.23%**，与 Thomas Fig. 2 的读图平台值 **34.2%** 一致（差值 +0.13 pp，在读图不确定度内）；
  瞬态曲线与 Fig. 2 在整个 2 年内差值 < 3.4 pp，早期略偏高。
- 全程无自由气（`Sg=0`），水饱和度和采收率均由水油毛管力 + 重力平衡主导。
- 该细网格结果作为**基准真值**，与单块双介质算例（`6.1`）的 34.99% 一致，验证了后者的
  重力排驱（GDP）符号修复正确。
