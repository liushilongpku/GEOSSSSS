# A0：双重介质压力交换综合验证报告

## 1. 报告范围

新的 A0 由两个相互独立、分别针对储集体积设置的子算例组成：

- [等体积 A0](equal_volume/report_zh.md)：`v_m=0.5`、`v_f=0.5`，两侧本征孔隙度均为 `0.2`；
- [不等体积 A0](unequal_volume/report_zh.md)：`v_m=0.95`、`v_f=0.05`，基质本征孔隙度为 `0.2`，裂缝本征孔隙度为 `1.0`。

两个子算例都只保留单相、封闭体系中的压力差驱动交叉流，均关闭重力、毛管压力和力学耦合。它们共同验证交叉流模块的方向、反向装配、储集量守恒和后向欧拉时间推进；第二个算例进一步验证 `fractureVolumeFraction` 对有效储集系数和最终平衡压力的影响。

## 2. 共同物理模型

设基质和裂缝压力分别为 `p_m`、`p_f`，有效储集系数分别为 `C_m`、`C_f`，交叉流传递系数为 `A`。两个封闭连续体的简化方程为

$$
C_m\frac{dp_m}{dt}=-A(p_m-p_f)
$$

$$
C_f\frac{dp_f}{dt}=+A(p_m-p_f)
$$

因此，压力差

$$
\Delta p=p_m-p_f
$$

满足

$$
\frac{d\Delta p}{dt}=-\lambda\Delta p,
\qquad
\lambda=A\left(\frac{1}{C_m}+\frac{1}{C_f}\right)
$$

连续时间基准为

$$
\Delta p(t)=\Delta p_0e^{-\lambda t}
$$

同时满足储集加权守恒

$$
C_mp_m+C_fp_f=\text{constant}
$$

所以最终平衡压力为

$$
p_{eq}=\frac{C_mp_{m,0}+C_fp_{f,0}}{C_m+C_f}
$$

有限时间步使用后向欧拉离散，其压差基准为

$$
\Delta p^{n+1}=q_{BE}\Delta p^n,
\qquad
q_{BE}=\frac{1}{1+\lambda\Delta t}
$$

连续时间基准检查模型的物理衰减规律，后向欧拉基准检查 GEOS 的实际时间离散和矩阵装配。

## 3. 两个子算例的区别

| 项目 | 等体积 A0 | 不等体积 A0 |
| --- | ---: | ---: |
| 基质 REV 体积分数 | `0.5` | `0.95` |
| 裂缝 REV 体积分数 | `0.5` | `0.05` |
| 基质本征孔隙度 | `0.2` | `0.2` |
| 裂缝本征孔隙度 | `0.2` | `1.0` |
| 基质储集系数 | `4.0e-10` | `3.8e-10` |
| 裂缝储集系数 | `4.0e-10` | `1.0e-10` |
| 加权平衡压力 | `1.5 MPa` | `1.7916667 MPa` |
| `q_BE`，`dt=0.02 s` | `0.8928571429` | `0.7763975155` |

两个网格在几何上都各自为 `1 m^3` 且完全重叠。对于不等体积 A0，不能把两个几何单元体积直接相加；物理 REV 体积由 `fractureVolumeFraction` 分配。

## 4. 等体积 A0 结果

![等体积 A0 压力交换结果](equal_volume/figures/A0_pressure_exchange.png)

图中 GEOS 的基质压力下降、裂缝压力上升，压力差单调衰减，并与后向欧拉参考曲线重合。结果如下：

| 检查量 | 结果 |
| --- | ---: |
| GEOS 返回码 | `0` |
| 时间步数 / 切步数 | `100 / 0` |
| 首步衰减因子相对误差 | `4.21e-8` |
| 压差曲线最大相对误差 | `4.39e-7` |
| 加权平均压力相对漂移 | `8.81e-8` |
| 最后归档压差 | `11.97 Pa` |

等体积 A0 证明了在两侧储集能力相同的情况下，交叉流方向、等量反向装配和平均压力守恒正确。最后的残余压差受浮点减法分辨率影响，不代表物理交换没有达到平衡。

## 5. 不等体积 A0 结果

![不等体积 A0 压力交换结果](unequal_volume/figures/20260822_vf095_phi1/A0_unequal_volume_pressure_exchange.png)

图中不等体积 A0 的基质和裂缝压力分别与后向欧拉参考曲线重合。由于基质储集系数较大，基质压力变化幅度较小；裂缝储集系数较小，裂缝压力变化幅度较大。最终压力趋向储集加权平衡值，而不是简单算术平均。

| 检查量 | 结果 |
| --- | ---: |
| GEOS 返回码 | `0` |
| 时间步数 / 切步数 | `100 / 0` |
| 后向欧拉参考 `q_BE` | `0.7763975155` |
| 压差曲线最大相对误差 | `5.682e-7` |
| 加权压力相对漂移 | `5.182e-8` |
| 最终压差 | `1.02e-5 Pa` |
| 平衡压力 | `1.7916667 MPa` |

该结果直接检验了 `fractureVolumeFraction=0.05` 的物理作用：裂缝只占 REV 的 `5%`，但其本征孔隙度为 `1.0`；这两个参数共同决定裂缝有效储集系数 `C_f`。

## 6. 综合判定

两个子算例都满足以下模块组装判据：

1. 初始高压基质向低压裂缝输运；
2. 基质压力下降、裂缝压力上升；
3. 压差始终单调衰减；
4. 压力历史符合后向欧拉参考；
5. 封闭体系的储集加权压力保持不变；
6. 不等体积情况下的最终压力由 `C_m`、`C_f` 加权，而不是使用算术平均。

因此，新的综合 A0 对压力差驱动双重介质交换模块给出了两层验证：等体积案例验证基本交叉流装配，不等体积案例验证 REV 体积分数和本征孔隙度共同作用下的储集与守恒。
