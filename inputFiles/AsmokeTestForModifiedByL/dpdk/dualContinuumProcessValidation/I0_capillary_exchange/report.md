# I0：毛管/渗吸驱替交换

## 验证目的

检查 compositional 双重介质交叉流是否把基质/裂缝毛管势差转换为组分转移和相体积分数变化。这是针对毛管/渗吸驱替过程的过程级验证。验证分为三个层次：毛管本构状态生成、交叉流残量的成对装配、以及接受时间步后的动态渗吸响应；只有第三层通过，才能宣称过程验证通过。

## 验证目标

算例建立两个共位、等体积单元，并满足：

- 两侧压力、温度、组分、孔隙度、渗透率和相对渗透率相同；
- 重力为零，且没有外部组分边界；
- 基质水相具有非零 entry pressure；
- 裂缝采用零毛管压力模型。

目标是观察到非零、等量反向的交叉流响应，并在封闭体系中观察到可测的组分/相分数变化。初始状态的水相毛管压力为

```text
Pc,m = 516014.125794 Pa,  Pc,f = 0 Pa.
```

因此水相势差包含非零项

```text
Phi_w = T * [(p_m - Pc,m) - (p_f - Pc,f)]
      = -T * 516014.125794 Pa,
```

按照 `PotGrad.hpp` 的符号约定，正确的毛管交叉流组装应导致两侧组分库存和相体积分数变化。正式封闭算例不设置外部压力边界，避免用压力边界引入或移除组分。为消除独立流动方程的共同压力零空间，正式输入采用 `PressurePorosity` 提供压力储集导数；这不是压力边界，不会向体系注入或移除组分。

## 物理图像

基质水相的毛管吸力较强，水从裂缝进入基质，基质气相被挤出并转移到裂缝。因此基质气相分数下降、裂缝气相分数上升；封闭体系中的 CO2 和 water 总量保持不变。

## 为什么能够验证

除毛管压力外，压力、重力和材料性质差异均被移除。算例直接输出两侧毛管压力，可以区分“本构状态没有生成”和“本构状态没有进入交叉流残量”；开启的质量残量诊断还可以检查矩阵/裂缝装配是否等量反向。没有外部组分源汇时，接受时间步之后的基质变化还必须由裂缝的反向变化平衡。因此该设计能定位毛管验证链条断在本构、装配还是时间推进，而不是仅凭一条压力曲线下结论。

这是过程级验证，不是闭式瞬态解析解验证。闭式解还需要额外指定约化两相本构和相质量储集关系；本输入中的 compositional flash 与 Brooks-Corey 模型在不增加近似的情况下不能可靠地化为一个初等 ODE。

## 结论和限制

**I0 通过动态过程判据。** 它验证了毛管压力状态生成、毛管交叉流残量的成对反向装配、封闭体系时间推进、可测的相分数/组分转移以及组分总量守恒。

早期使用 `BiotPorosity` 的诊断版本因共同压力零空间在首步线性系统中秩亏而失败；该失败及矩阵秩证据保留在历史日志中。正式输入改用压力依赖孔隙度物性提供压力储集项，未增加压力边界，因此不改变本验证的封闭渗吸物理目标。带压力锚定的版本仍不作为正式证据。
